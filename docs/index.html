Getting Started

Yorumi CLI is a command-line anime watcher that searches AnimePahe, resolves streams through Yorumi's scraper, and opens episodes in a small mpv media player window.

Terminal first

Run yorumi-cli "Frieren", choose an episode, and watch without opening the Yorumi website.

Yorumi powered

The CLI uses Yorumi's backend proxy so blocked HLS segments can still play in mpv.

Installation

The easiest way to install Yorumi CLI is using the official PowerShell installer.

Windows

The PowerShell installer installs Yorumi CLI and attempts to install mpv with Winget when it is missing.

PS> iwr -useb https://raw.githubusercontent.com/davenarchives/yorumi-cli/main/install.ps1 | iex

Linux / macOS

$ curl -sL https://raw.githubusercontent.com/davenarchives/yorumi-cli/main/install.sh | bash

First Run

Ready: the CLI uses the hosted Yorumi API by default. Install, run yorumi-cli, search, and watch. 
PS> yorumi-cli

Basic Usage

PS> yorumi-cli
PS> yorumi-cli "One Piece"
PS> yorumi-cli -e 1 "Frieren"
PS> yorumi-cli --episode 1 "Frieren"
PS> yorumi-cli -r "1-5" "Naruto"

Keep It Updated

Run the built-in updater any time you want the latest CLI version and dependencies.

PS> yorumi-cli --update

Interactive Menu

When available, Yorumi CLI uses fzf or rofi for anime and episode selection. Without either tool, the built-in numbered menu is used.

PS> yorumi-cli
# search anime -> select anime -> choose episode

Troubleshooting

mpv does not open

Run winget install --id shinchiro.mpv -e, reopen the terminal, then run mpv --version.

Browser opens instead of player

That means an old CLI build is still linked. Run npm link again inside yorumi-cli.

Video exits immediately

Check that the hosted API is returning /api/scraper/playable-stream URLs with proxyMedia=1.
