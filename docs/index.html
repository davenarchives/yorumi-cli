Getting Started

Yorumi CLI is a command-line anime watcher that searches AnimePahe, resolves streams through Yorumi's scraper, and opens episodes in a small mpv media player window.

Terminal first

Run yorumi-cli "Frieren", choose an episode, and watch without opening the Yorumi website.

Yorumi powered

The CLI uses Yorumi's backend proxy so blocked HLS segments can still play in mpv.

Installation

The easiest way to install Yorumi CLI is using the official PowerShell installer.

Windows

PS> iwr -useb https://raw.githubusercontent.com/davenarchives/yorumi-cli/main/install.ps1 | iex

Linux / macOS

$ curl -sL https://raw.githubusercontent.com/davenarchives/yorumi-cli/main/install.sh | bash

First Run

Ready: the CLI uses the hosted Yorumi API by default. Install, run yorumi-cli, search, and watch. 
PS> yorumi-cli

Basic Usage

PS> yorumi-cli
PS> yorumi-cli "One Piece"
PS> yorumi-cli -e 1 "Frieren"
PS> yorumi-cli --episode 1 "Frieren"
PS> yorumi-cli -r "1-5" "Naruto"

Window size

The mpv window opens at 960x540 by default. Use --size for a smaller or larger popup.

PS> yorumi-cli -e 1 "Frieren" --size 854x480
PS> yorumi-cli -e 1 "Frieren" --size 1280x720

Configuration

Use flags for one-off runs or environment variables for defaults.

PS> yorumi-cli "Frieren" --api-base https://yorumi-sigma.vercel.app/api
PS> $env:YORUMI_API_URL="https://api.example.com/api"
PS> $env:YORUMI_PLAYER_SIZE="854x480"

Interactive Menu

When available, Yorumi CLI uses fzf or rofi for anime and episode selection. Without either tool, the built-in numbered menu is used.

PS> yorumi-cli
# search anime -> select anime -> choose episode

Deployment

There are two deployable parts: the Yorumi API and this documentation site.

Yorumi API

Avoid treating serverless as a long-term video pipe. The CLI can proxy media through Yorumi for local use, but public hosting should be tested carefully for bandwidth and CPU limits.
  1. The default CLI API is https://yorumi-sigma.vercel.app/api.
  2. Set environment variables on the hosted API when optional services need keys.
  3. Verify /api/scraper/search/animepahe?q=frieren responds.
  4. Run the CLI with --api-base https://your-api.example.com/api.

Docs on GitHub Pages

PS> git add docs README.md package.json scripts
PS> git commit -m "Add documentation site"
PS> git push origin main

In GitHub, open Settings -> Pages, choose Deploy from branch, select main and /docs.

Publishing

When you want npm install -g yorumi-cli, remove private: true, make the package self-contained, and publish.

PS> npm login
PS> npm version patch
PS> npm publish --access public
The CLI calls the hosted Yorumi API and does not require local backend files.

Troubleshooting

mpv does not open

Install mpv with winget, reopen the terminal, then run mpv --version.

Browser opens instead of player

That means an old CLI build is still linked. Run npm link again inside yorumi-cli.

Video exits immediately

Check that the hosted API is returning /api/scraper/playable-stream URLs with proxyMedia=1.
